# Code Generation Test Prompts

## Python

### Basic
Write a Python function to calculate factorial of a number. Only output code.

### Intermediate
Write a Python class for a binary search tree with insert, search, and delete operations. Only output code.

### Advanced
Write a Python async HTTP server using aiohttp that serves a REST API with CRUD operations for a todo list. Only output code.

## Rust

### Basic
Write a Rust function to check if a string is a palindrome. Only output code.

### Intermediate
Write a Rust struct for a generic linked list with push, pop, and peek operations. Only output code.

### Advanced
Write a Rust program that uses tokio to download multiple URLs concurrently and save them to files. Only output code.

## TypeScript

### Basic
Write a TypeScript function to flatten a nested array. Only output code.

### Intermediate
Write a TypeScript interface and implementation for a LRU cache with get and set methods. Only output code.

### Advanced
Write a TypeScript React component for an infinite scroll list with loading states and error handling. Only output code.

## SQL

### Basic
Write a SQL query to find the second highest salary from an employees table. Only output code.

### Intermediate
Write a SQL query to find customers who have made orders in every month of the current year. Only output code.

### Advanced
Write a SQL query to calculate running totals and moving averages for daily sales data. Only output code.
