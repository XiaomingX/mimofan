## 测试状态说明

| 标记 | 含义 |
|------|------|
| ✅ | 通过 |
| ❌ | 代码问题，需要修复 |
| ⚠️ | 外部服务问题（如 API 余额不足），非代码问题 |
| - | 未测试 |

### 常见失败原因

1. **HTTP 402 Payment Required** - API 账户余额不足，需要充值
2. **timeout 命令不存在** - macOS 环境问题，已通过 `run_with_timeout` 解决
3. **ls/find 命令失败** - 目录不存在，已添加 `|| true` 忽略错误
